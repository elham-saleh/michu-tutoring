# Michu Tutoring

A multi-page pure HTML website for **Michu Tutoring**, connecting local students/parents in Ethiopia with online tutors for safer, home-based learning sessions[cite: 3, 5].

## Course & Assignment
- **Course:** COSC 3081 — Web Programming I (Chapter 2, Assignment 1)
- **Tech Stack:** HTML5 only (no CSS, no JavaScript)[cite: 3]

## Project Structure
- `index.html` — Home page introducing online tutoring in Ethiopia and how to get started[cite: 3].
- `pages/tutors.html` — Available subjects, session schedule, and weekly rates table[cite: 3].
- `pages/contact.html` — Registration/request form and contact details[cite: 3].
- `images/` — Website logo and icon assets (`michu-logo.svg`, `michu-icon.svg`)[cite: 3, 5, 9].

## Validation & Compliance
- Uses semantic layout elements (`header`, `nav`, `main`, `footer`) and proper heading hierarchy (`h1` and `h2`) across all pages[cite: 3].
- Validated with the W3C Markup Validator (`validator.w3.org`) with zero errors[cite: 3, 4].
